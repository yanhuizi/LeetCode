# LeetCode C语言刷题

这个仓库用来记录我的 LeetCode C 语言刷题代码和复盘。

## 文件夹说明

- `Array`: 数组题，比如二分查找、双指针
- `LinkedList`: 链表题，主要练指针
- `String`: 字符串题
- `StackQueue`: 栈和队列题
- `Tree`: 二叉树题
- `DP`: 动态规划题
- `Review`: 错题本、复盘、常见套路

## 每日流程

1. 选一道题。
2. 先自己想 20-30 分钟。
3. 用 C 语言写代码。
4. 在 LeetCode 提交。
5. 把卡住的地方记录到 `Review/错题本.md`。
6. 做完一题提交一次 Git。
