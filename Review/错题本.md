### 209 长度最小的子数组

- 日期：2026-07-30
- 错误原因：
1.break 只能跳出它所在的最近一层循环，不能跳出 if。因为 if 不是循环。
2.int minLen = numsSize + 1这里 +1 是为了设置一个“不可能出现的很大初始值”。
3.用两层for循环暴力法写会超时，时间算法度是O(n^2)，要求是O(n)或者O(n log(n))才行。
int minSubArrayLen(int target, int* nums, int numsSize) {
    int minLen=numsSize+1;
    for(int i=0;i<numsSize;i++){
        int sum=0;
        for(int j=i;j<numsSize;j++){
            sum+=nums[j];
            if (sum>=target)
            {
                int len=j-i+1;
                if (len<minLen)
                {
                    minLen=len;
                }
                break;
            }
        }
    }
    if (minLen==numsSize+1){
        return 0;
    }else{
        return minLen;
    } 
}
这题要用 滑动窗口，时间复杂度是 O(n)；
4.暴力法是固定 i，让 j 一直往右试。而滑动窗口是right 一直往右扩，sum 够了以后，left 一直往右缩；

- 正确思路：用滑动窗口，right 一直往右扩，sum 够了以后，left 一直往右缩。
