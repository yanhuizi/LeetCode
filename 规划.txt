五、目录建议

你现在的目录可以保持这样：

D:\LeetCode
├─ Array
├─ LinkedList
├─ String
├─ StackQueue
├─ Tree
├─ DP
├─ Review
└─ ACM

其中：

1. Array 放数组题。
2. LinkedList 放链表题。
3. String 放字符串题。
4. StackQueue 放栈和队列题。
5. Tree 放二叉树题。
6. DP 放动态规划题。
7. Review 放错题本和套路总结。
8. ACM 放完整输入输出程序，专门准备科软机试。
